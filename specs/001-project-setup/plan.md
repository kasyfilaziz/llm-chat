## Summary

Initialize the Lumina project as a compilable, runnable Dioxus 0.7 desktop application targeting Windows, macOS, and Linux via system native WebView. The scaffold includes: `Cargo.toml` with Dioxus desktop + SQLite stub dependencies, `Dioxus.toml` for CLI configuration, Tailwind CSS v4 via zero-config `dx` CLI integration, a placeholder UI displaying the app name and version, and a developer quickstart document. Success is defined as `dx serve` opening a desktop window with the Lumina placeholder UI and hot-reload functioning on source file saves.

---

## Technical Context

**Language/Version**: Rust stable 1.80.0+  
**Primary Dependencies**: `dioxus 0.7` (desktop feature), `rusqlite 0.31` (bundled feature)  
**Storage**: SQLite stub — `rusqlite` with `bundled` feature; no active schema  
**Testing**: `cargo test` (unit tests only at scaffold stage; no UI test framework)  
**Target Platform**: Desktop — Windows (Edge WebView2), macOS (WKWebView), Linux (libwebkit2gtk-4.1)  
**Project Type**: Desktop application  
**Performance Goals**: App window opens within 3 seconds of binary launch on a development machine  
**Constraints**: Binary size ~10MB target (system WebView, no bundled browser engine); no remote network calls in scaffold  
**Scale/Scope**: Single developer workstation; greenfield — no existing codebase
