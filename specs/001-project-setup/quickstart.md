## Prerequisites

Complete **all** steps for your operating system before proceeding.

### 1. Rust (all platforms)

```bash
# Install rustup if not already installed
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Ensure stable toolchain (1.80.0+)
rustup update stable
rustup default stable

# Verify
rustc --version   # must be >= 1.80.0
```

### 2. Dioxus CLI (all platforms)

```bash
cargo install dioxus-cli

# Verify
dx --version      # must be 0.7.x
```

### 3. Linux System Dependencies

> **Skip this section on Windows and macOS** — system WebView is bundled.

#### Ubuntu / Debian / Pop!_OS
```bash
sudo apt update && sudo apt install \
  libgtk-3-dev \
  libwebkit2gtk-4.1-dev \
  libssl-dev \
  pkg-config \
  build-essential
```

#### Fedora
```bash
sudo dnf install \
  gtk3-devel \
  webkit2gtk4.1-devel \
  openssl-devel \
  pkgconf-pkg-config \
  gcc-c++
```

#### Arch Linux
```bash
sudo pacman -S --needed \
  gtk3 \
  webkit2gtk-4.1 \
  pkgconf \
  base-devel
```

> ⚠️ **Important**: Install `libwebkit2gtk-4.1` specifically. The older `4.0` version causes linker errors.

## Running the App

### Development (with hot-reload) — Recommended

```bash
dx serve
```

- Opens a native desktop window automatically.
- Saves a Rust source file → window updates in seconds (no restart needed).
- Use `dx serve --hotpatch` for sub-second logic updates (experimental).

### Build & Run (production binary)

```bash
dx build --release
./dist/lumina        # Linux/macOS
.\dist\lumina.exe    # Windows
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `rustc` version too old | Run `rustup update stable` |
| `dx: command not found` | Run `cargo install dioxus-cli`, ensure `~/.cargo/bin` is in `$PATH` |
| Linux linker error: `cannot find -lwebkit2gtk-4.1` | Install the `-dev` packages listed above for your distro |
| Linux: app window is black / blank | The app sets `WEBKIT_DISABLE_COMPOSITING_MODE=1` automatically in debug builds |
| Port conflict on `dx serve` | Another `dx serve` instance is running — kill it or use a different terminal |
